# M5 Playbook — Experience & Replay

## Goal

Turn the engineering engine into an app people actually enjoy opening and replaying.

## Minimum references

`app/AGENTS.md`, `UX_SPEC.md`, `COMMENTARY_SPEC.md`, `MAP_ARCHITECTURE.md`, Drive DNA spec.

## Work units

1. Refine ready/start screen and recorder health.
2. Build distraction-minimized live drive mode.
3. Build trip history and rich result screen.
4. Implement original Drive DNA signature visual.
5. Implement provider-neutral route map.
6. Create single replay clock and scrubbing.
7. Synchronize marker/path/graphs/events.
8. Add camera overview/follow transitions.
9. Add event pulse and anchored bubble animation.
10. Implement procedural commentary tone packs with cooldown/context.
11. Expand bubble into real telemetry explanation.
12. Add replay-speed controls and pause semantics.
13. Implement reduced motion.
14. Add storage manager/export UX.
15. Add shareable redacted trip card if it can be done without scope damage.

## Acceptance

- replay synchronization remains correct at multiple speeds;
- animations are fun but not noisy;
- reduced-motion mode is usable;
- commentary never changes safety/scoring;
- result screen makes confidence/integrity visible;
- map failure does not destroy replay telemetry.
